# ADR 0010: Present Codex text state through the existing contextual surfaces

- Status: accepted
- Date: 2026-08-28

## Decision

Keep the approved Omarchy-compatible shell as the visual underlay and present M05 Codex text state only through the
existing small top-bar Orb, contextual capsule, approval sheet, and result stage. Keep private reasoning out of the
default contract. Translate authoritative runtime correlation, control, approval, and artifact data through the strict
browser replay adapter before it reaches the shared surface package.

## Consequences

Agent OS gains a real text composer and streaming/result/approval presentation without introducing a persistent chat
window or redesigning the shell. Studio evidence remains deterministic and browser-only; the native Codex and named-pipe
boundaries stay in the trusted runtime repository.
